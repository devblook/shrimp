# Shrimp 🛏️

Shrimp is a Minecraft plugin that aims to facilitate the saving of homes or positions established by a player, with the practicality of connections to databases, the idea is to guide a scalable project.

## Features 🔎
* Mysql, Mongo and Local (json files) support
* Easy to use and configure with a simple configuration file
* Support for multiple homes per player
* Support for multiple worlds
* ~~Support for multiple servers~~ (soon...)

## Commands ️💻
* `/home` - Teleport to your home
* `/sethome` - Set your home
* `/delhome` - Delete your home
* `/homes` - Open gui with all homes (if you have more than one)
* `/shrimp` - Plugin information (You need permission to use this command)
* `/shrimp reload` - Reload the plugin configuration (You need permission to use this command)
* `/shrimp save` - Save the plugin configuration (You need permission to use this command)
